# نقره‌یار — نمونه فرانت‌اند با Next.js

این پروژه یک بازسازی فرانت‌اند با طراحی مدرن‌تر و راست‌چین است. صفحات شامل خانه، فروشگاه، جست‌وجو، جزئیات محصول، سبد خرید، درباره ما، تماس با ما و سؤالات متداول هستند.

## اجرا
1. Node.js نسخه 18.17 یا جدیدتر نصب باشد.
2. در پوشه پروژه اجرا کنید:
   ```bash
   npm install
   npm run dev
   ```
3. مرورگر: http://localhost:3000

## امکانات نمایشی
- ریسپانسیو برای موبایل، تبلت و دسکتاپ
- جست‌وجو، دسته‌بندی، مرتب‌سازی و فیلتر سقف قیمت
- افزودن به سبد خرید، تغییر تعداد، حذف محصول و ذخیره سبد در localStorage
- صفحات محصول و محصولات مشابه
- فرم تماس و FAQ تعاملی
- متادیتای پایه و HTML راست‌چین فارسی

## مواردی که برای نسخه عملیاتی باید تکمیل شوند
- اطلاعات محصولات، تصاویر، قیمت‌ها و دسته‌بندی‌های واقعی
- اتصال به API یا CMS و پایگاه داده
- ورود/ثبت‌نام و مدیریت حساب مشتری
- ایجاد سفارش سمت سرور، موجودی، ارسال و مالیات/هزینه‌ها
- درگاه پرداخت واقعی و اعتبارسنجی امن
- ارسال واقعی فرم تماس/خبرنامه
- بررسی دقیق سایت مرجع و تطبیق جزئیات برند و صفحات

**توجه:** قیمت‌ها، نام محصولات، اطلاعات تماس و فرم‌ها در این پروژه نمونه هستند. این پروژه پرداخت یا ثبت سفارش واقعی انجام نمی‌دهد. تصاویر از Unsplash بارگیری می‌شوند و برای نمایش تصاویر به اینترنت نیاز است.
